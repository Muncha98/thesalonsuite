Matching Rod Size to Wave Pattern

Perm rod diameter directly determines final curl size — smaller rods create tighter spirals, larger rods create soft, loose waves. Processing time also varies by rod size and hair porosity, so a one-size-fits-all timer risks over- or under-processing.

Choosing the right rod size and timing range up front, then confirming with a test curl, keeps the result predictable.

🌀 How to use this guide

  1. Select the desired wave pattern — tight spiral, medium volume curl, or soft beach wave.
  2. Use the matching rod size and wrap evenly for a consistent diameter.
  3. Process within the given time range, checking a test curl before neutralizing.
Example: a soft beach wave uses purple/orange rods (14–16mm) and processes in 8–12 minutes.

Rules to Remember

  • 1. Always test curl before neutralizing: A test curl confirms the perm has actually taken before you commit to neutralizing — skipping it risks an under-processed result that relaxes within days.
  • 2. Fine hair processes faster: Check early on fine or previously colored hair — it typically processes faster than the standard range for a given rod size.
